# French photo captions

When writing or translating French captions, titles, or comments for photos shared with friends and family:

## Style

- **Short and succinct.** Captions, not essays. One short sentence or a fragment is usually enough.
- **Friendly and fun, not over-the-top.** Avoid "magnifique !!!", strings of exclamation marks, or empty enthusiasm. Warm beats gushing.
- **Casual register.** "Tu" by default. Contractions are fine ("c'est", "y'a", "j'ai").
- **Informal abbreviations are welcome.** "Aprem'" (après-midi), "resto" (restaurant), "anniv" (anniversaire), "p'tit", "ouais", "perso", "ça va". Use them when they fit the vibe.

## Name corrections

The user's keyboard cannot type accents on these names. Always add the accent aigu when you see them, even if the user typed the unaccented form:

- "Pape" → "Papé"
- "Mame" → "Mamé"

Apply this in both translation output and any French text you generate that mentions them.
